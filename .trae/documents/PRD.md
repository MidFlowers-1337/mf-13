## 1. 产品概述

《矿车调度站》是一款策略类网页小游戏，玩家在6×6轨道网格中担任调度员，通过切换道岔引导矿车将矿石送到对应颜色的仓库。游戏考验玩家的反应速度和策略规划能力，适合所有年龄段玩家。

## 2. 核心功能

### 2.1 功能模块
1. **游戏主界面**：6×6轨道棋盘、矿车显示、道岔切换
2. **信息面板**：关卡、剩余时间、分数、目标、最高分显示
3. **控制系统**：开始、暂停、继续、重开按钮
4. **关卡系统**：3个难度递增的关卡设计
5. **状态反馈**：通关/失败提示、操作反馈动画

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 游戏主页面 | 轨道棋盘 | 6×6网格，显示道岔方向，矿车移动动画 |
| 游戏主页面 | 信息面板 | 实时显示游戏状态信息 |
| 游戏主页面 | 控制按钮 | 开始/暂停/继续/重开功能 |
| 游戏主页面 | 关卡选择 | 显示当前关卡，通关后解锁下一关 |

## 3. 核心流程

玩家进入游戏 → 选择关卡 → 点击开始 → 矿车自动驶入 → 玩家点击道岔切换方向 → 矿车移动 → 正确送达加分/错误送达或碰撞失败 → 达到目标进入下一关/失败重玩

```mermaid
    H --> L{"达成目标?"}
    L -->|是| --> M["进入下一关"]
    L -->|否| --> D
    I --> N["点击重开"]
    N --> C
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：工业风深色主题，以深灰色为背景，配合红、蓝、黄三色矿石的高亮色
- **辅助色**：铁轨金属质感，轨道格子采用金属灰色
- **按钮风格**：工业风按钮，带有金属边框，点击有按压效果
- **字体**：采用等宽字体配合工业风数字显示
- **布局**：信息面板在顶部，棋盘居中，控制按钮在底部
- **动画**：矿车移动有平滑过渡动画，道岔切换有转动动画

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|-----------|-------------|-------------|
| 游戏主页面 | 信息面板 | 关卡、时间、分数、目标、最高分 |
| 游戏主页面 | 轨道棋盘 | 6×6网格、道岔方向指示、矿车、仓库 |
| 游戏主页面 | 控制按钮 | 开始、暂停、继续、重开 |
| 游戏主页面 | 状态提示 | 通关/失败弹窗，正确送达动画 |

### 4.3 响应式设计
- **桌面端**：棋盘居中，信息面板顶部，控制按钮底部
- **移动端**：自适应屏幕大小，触摸优化，按钮足够大便于点击
- **触摸优化**：道岔点击区域扩大，防止误触

### 4.4 视觉细节
- 道岔方向用箭头清晰指示
- 矿车带有矿石颜色明显区分
- 仓库用对应颜色标识
- 选中的道岔有高亮边框
- 正确送达有闪光效果
- 失败有震动和红色警告效果
