# 🚂 矿车调度站 Minecart Dispatch Station

一款基于 React + TypeScript + Vite 的策略调度小游戏。玩家通过切换轨道道岔，引导不同颜色的矿车将矿石送到对应颜色的仓库。

## ✨ 游戏特色

- 🎯 **直观操作**：点击道岔格子切换方向，矿车自动沿轨道运行
- 🎨 **三种颜色**：红🔴、蓝🔵、黄🟡 矿石必须送入对应颜色仓库
- 🧩 **3 个官方关卡**：难度递进的轨道布局，从新手训练到调度大师
- 🛠️ **关卡编辑器**：自由创作属于你自己的关卡
- 🎓 **训练模式**：步进式练习，慢慢研究最佳路线
- 💾 **本地存档**：自定义关卡自动保存到浏览器本地
- 📤 **导入导出**：支持 JSON 格式的关卡导入导出
- 💡 **多种辅助模式**：提示模式、慢速模式、目的地标记
- 📊 **详细反馈**：失败精确到矿车编号、颜色、位置和原因
- 📜 **操作日志**：实时记录最近发生的所有事件
- 🏆 **进度保存**：关卡解锁、最高分、最快通关时间自动存档
- 📱 **移动端友好**：适配手机屏幕和触摸操作

## 🎮 游戏玩法

### 基本规则

1. 矿车会从绿色「入口」随机颜色自动驶出
2. 矿车沿轨道自动移动，遇到「道岔」时按其当前方向转向
3. **点击道岔格子**可切换其方向（右下角箭头指示当前方向）
4. 将矿车送入**相同颜色**的仓库即可得分（每车 +10 分）
5. 达到目标配送数或分数即可通关

### 失败条件

| 失败类型 | 说明 |
|---------|------|
| ❌ 送错仓库 | 矿车颜色与进入的仓库颜色不匹配 |
| 💥 矿车相撞 | 两辆矿车在同一格相撞 |
| 🛤️ 矿车出轨 | 矿车驶出轨道边界或进入空格 |
| ⏰ 时间耗尽 | 时间到了仍未完成目标 |

### 辅助功能

| 功能 | 说明 |
|-----|------|
| 💡 **提示模式** | 矿车快到道岔时，若当前设置会导致送错仓库，则自动高亮该道岔 |
| 🐌 **慢速模式** | 矿车移动速度和生成间隔减半，适合新手练习 |
| 👁️ **目的地标记** | 每辆矿车右上角显示其目标颜色的小图标 |

## 🛠️ 关卡编辑器

### 功能介绍

关卡编辑器让你可以自由创作属于自己的矿车调度关卡。

### 操作说明

1. 点击主页面的「关卡编辑」按钮进入编辑器
2. 选择左侧工具栏中的工具（擦除、轨道、道岔、入口、仓库）
3. 点击棋盘格子放置对应的元素
4. 点击已放置的元素可以在右侧属性面板调整属性：
   - **入口**：调整矿车驶出方向（上/右/下/左）
   - **仓库**：调整仓库颜色（红/蓝/黄）
   - **道岔**：调整道岔的两个方向和当前朝向

### 关卡验证

保存关卡前系统会自动检查以下问题，并高亮显示有问题的格子：

| 检查项 | 说明 |
|-------|------|
| ❌ 缺少入口 | 关卡至少需要一个入口 |
| ❌ 缺少仓库 | 关卡至少需要一个仓库 |
| ❌ 颜色重复 | 每个仓库颜色应该是唯一的 |
| ⚠️ 入口无出口 | 入口的轨道无法到达任何仓库 |
| ⚠️ 仓库无入口 | 仓库没有轨道与入口连通 |
| ⚠️ 孤立轨道 | 轨道段没有与入口连通 |

### 关卡设置

点击右侧「关卡设置」旁的齿轮图标可展开高级设置：

- **关卡名称**：自定义关卡名称
- **描述**：关卡描述文字
- **矿车颜色**：选择本局会出现的矿车颜色
- **目标分数**：达到多少分算通关
- **目标配送**：需要配送多少辆矿车
- **生成间隔**：矿车生成的时间间隔（毫秒）
- **移动间隔**：矿车移动的时间间隔（毫秒）
- **时间限制**：关卡时间限制（秒）

## 🎓 训练模式

### 功能介绍

训练模式专为练习和研究路线设计，没有时间限制，不会失败。

### 操作方式

| 按钮 | 功能 |
|-----|------|
| ➕ **生成矿车** | 手动生成一辆随机颜色的矿车 |
| ⏭️ **前进一步** | 让所有矿车同时向前移动一格 |
| ↩️ **回退一步** | 撤销上一步操作，矿车回到之前的位置 |
| 🔄 **重置** | 清空所有矿车，重新开始 |

### 使用技巧

1. 先点击「生成矿车」放出 1-2 辆矿车
2. 观察矿车的行进路线
3. 遇到道岔时可暂停，点击道岔切换方向
4. 点击「前进一步」查看移动结果
5. 如果走错了，点击「回退一步」撤销
6. 多练习找到最佳的调度时机和路线

### 地图选择

点击右上角「切换地图」可选择训练地图：
- **官方关卡**：游戏内置的 3 个关卡
- **我的关卡**：你自己创建并保存的自定义关卡

## 📤 导入与导出

### 导出关卡

1. 进入关卡编辑器
2. 点击「导出」按钮
3. 浏览器会自动下载一个 `.json` 文件
4. 这个文件包含了关卡的所有数据，可以分享给朋友

### 导入关卡

1. 进入关卡编辑器
2. 点击「导入」按钮
3. 可以选择 JSON 文件，或直接粘贴 JSON 文本
4. 点击「导入」按钮加载关卡
5. 如果格式有问题，会显示具体的错误原因

### 关卡 JSON 格式

```json
{
  "name": "我的关卡",
  "description": "这是一个示例关卡",
  "oreColors": ["red", "blue", "yellow"],
  "spawnInterval": 6000,
  "moveInterval": 1200,
  "targetScore": 60,
  "targetDeliveries": 6,
  "timeLimit": 180,
  "grid": [
    [
      { "type": "entrance", "entranceDirection": "right" },
      { "type": "track" },
      { "type": "warehouse", "color": "red" }
    ]
  ]
}
```

### 导入错误说明

导入失败时会显示具体的错误原因，包括：

| 错误类型 | 说明 |
|---------|------|
| JSON 解析失败 | JSON 语法错误，无法解析 |
| 缺少关卡名称 | 对象中没有 `name` 字段 |
| 缺少棋盘网格 | 没有 `grid` 字段或格式不对 |
| 网格行数错误 | grid 不是 6 行 |
| 行列数错误 | 某一行不是 6 列 |
| 格子 type 无效 | 格子类型不是 track/switch/entrance/warehouse/empty |
| 入口方向无效 | entranceDirection 不是 up/down/left/right |
| 仓库颜色无效 | color 不是 red/blue/yellow |
| 道岔配置缺失 | switch 类型缺少 switchConfig |
| 道岔方向无效 | 道岔的方向配置不对 |
| 道岔 current 无效 | current 必须是 0 或 1 |

## 🏗️ 项目结构

```
src/
├── components/              # UI 组件
│   ├── GameBoard.tsx        # 游戏棋盘（含暂停遮罩）
│   ├── Cell.tsx             # 单个格子（轨道/道岔/入口/仓库）
│   ├── Cart.tsx             # 矿车（含目的地标记）
│   ├── InfoPanel.tsx        # 信息面板（时间/分数/进度等）
│   ├── ControlButtons.tsx   # 开始按钮 + 游戏说明
│   ├── EventLogPanel.tsx    # 设置 + 关卡选择 + 操作日志 + 控制按钮
│   ├── StatusModal.tsx      # 通关/失败弹窗（含详细原因）
│   ├── LevelEditor.tsx      # 关卡编辑器（新建/编辑/导入/导出）
│   └── TrainingMode.tsx     # 训练模式（步进/回退/重置）
├── data/
│   ├── levels.ts            # 3 个官方关卡的布局定义
│   └── customLevels.ts      # 自定义关卡的本地存储管理
├── hooks/
│   └── useGameEngine.ts     # 游戏核心逻辑引擎（矿车生成/移动/碰撞/胜负判定）
├── store/
│   └── gameStore.ts         # Zustand 全局状态管理
├── types/
│   └── game.ts              # 全部 TypeScript 类型定义
├── utils/
│   ├── gameLogic.ts         # 纯函数工具（位置、方向、颜色等）
│   └── levelValidator.ts    # 关卡验证工具（连通性检查等）
├── pages/
│   └── Home.tsx             # 游戏主页
└── index.css                # 全局样式 + Tailwind + 动画
```

## 🚀 快速开始

### 环境要求

- Node.js ≥ 18
- npm ≥ 9（或使用 pnpm / yarn）

### 安装依赖

```bash
npm install
```

### 开发模式（热更新）

```bash
npm run dev
```

默认启动在 `http://localhost:5173`

### 类型检查

```bash
npm run check
```

### 代码 Lint

```bash
npm run lint
```

### 生产构建

```bash
npm run build
```

构建产物在 `dist/` 目录

### 预览构建结果

```bash
npm run preview
```

9. **操作日志**
   - 实时滚动显示：矿车生成、送达、道岔切换、暂停/继续、通关/失败

    - 375px 宽度下所有文字不溢出
    - 按钮可点击区域足够大（≥44px）

## 📝 数据存储

游戏使用浏览器 `localStorage` 自动保存以下数据（无需登录）：

| Key | 说明 |
|-----|------|
| `minecart_highscore` | 历史全局最高分 |
| `minecart_progress` | 每关解锁状态、最高分、最快通关时间 |
| `minecart_settings` | 辅助设置（提示/慢速/目的地标记开关状态）|
| `minecart_eventlog` | 最近 100 条操作日志 |
| `minecart_custom_levels` | 自定义关卡数据（名称、棋盘、设置等） |
